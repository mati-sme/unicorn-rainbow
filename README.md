# Unicorn Rainbow

A no-reading tablet game for a 4-year-old: every action speaks the word in **Hebrew, then Spanish** (bundled voice clips, works offline).

- Play: https://mati-sme.github.io/unicorn-rainbow/ (landscape, tap the big green button to start)
- Android: download the APK from the latest Release.
- Parents: hold the gear (top right) for 3 seconds for music / sounds / voice language / reset.

All art is original and drawn in code. Voice: Microsoft Edge neural voices (he-IL Hila, es-AR Elena) pre-generated with edge-tts.
